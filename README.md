# Self-Healing Microservices with Chaos Engineering

> Status: 🚧 Phase 1 — Foundation & Architecture

## Project Overview
A Kubernetes-based microservices platform on Amazon EKS, engineered to
demonstrate automatic recovery from intentionally injected failures, with
recovery time measured via Prometheus/Grafana and failures injected via Chaos Mesh.

## Why This Project Exists
To prove reliability-engineering thinking, not just "I can deploy to Kubernetes":
defining a recovery objective, breaking the system on purpose, and measuring
whether the platform meets that objective.
